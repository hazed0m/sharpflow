## Editing Strategy (STRICT)

- Only modify the smallest possible part of the code.
- DO NOT rewrite entire files.
- DO NOT refactor unrelated code.
- DO NOT reformat or change structure unless explicitly asked.
- Preserve all existing logic, comments, and formatting.
- Show changes as minimal diffs.

## Code Changes

- Prefer patch-style updates over full rewrites.
- If a fix can be done in 1–5 lines, do NOT touch anything else.
- Never "clean up" code unless requested.

## When unsure

- Ask before making large changes.
